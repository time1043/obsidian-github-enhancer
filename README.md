# Obsidian GitHub Enhancer

Enhance your GitHub experience for Obsidian notes.

## Features

- Renders `![[image.svg]]` syntax to images on GitHub
- Supports SVG, PNG, JPG, JPEG, GIF, WebP

## Install

1. Install [Tampermonkey](https://www.tampermonkey.net/)
2. [Click here to install the script](https://raw.githubusercontent.com/time1043/obsidian-github-enhancer/mvp/userscript/obsidian-github-enhancer.user.js)
